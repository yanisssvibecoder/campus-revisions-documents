analogy

Pour aller au gym, ton abonnement mensuel reste le même ; un billet de bus acheté pour chaque visite augmente avec le nombre de visites. Le coût moyen de l’abonnement par visite baisse si tu y vas plus souvent.

explanation

  1. Un coût variable total suit le volume : deux fois plus d’unités entraîne deux fois plus de coûts variables si le prix des ressources ne change pas. Le coût variable par unité reste alors constant.

  2. Un coût fixe total ne change pas avec le volume à l’intérieur du segment significatif. Le coût fixe par unité est CF/Q : il baisse quand Q augmente. Cela n’implique pas une économie du montant fixe total.

  3. Un coût mixte comporte une partie fixe et une partie variable. Un salaire de vendeur peut être 1 000 $ de base plus 2 $ par vente. La formule du coût total est CT = CF + cv×Q.

  4. Le segment significatif est la plage où ces hypothèses sont raisonnables. Si la production dépasse la capacité d’une usine, une nouvelle usine ou un superviseur peut faire monter les coûts fixes d’un palier. Vérifie toujours la capacité avant de prolonger une formule.

  5. Le coût moyen CT/Q répartit tous les coûts sur les unités. Le coût marginal est le coût de l’unité supplémentaire. Tant que les coûts fixes ne changent pas, il peut être très inférieur au coût moyen. Ne les interchange pas pour une décision.

  6. Au franchissement d'un palier, le coût marginal peut inclure un nouveau coût fixe. Par exemple, si l'unité supplémentaire nécessite un autre superviseur, son coût n'est pas seulement la matière utilisée. Une conclusion valable à l'intérieur du segment ne s'étend pas automatiquement au-delà.

vocabulary

  1. term

    Coût fixe total

    meaning

    Montant inchangé quand le volume varie dans le segment significatif.

  2. term

    Coût variable unitaire

    meaning

    Montant associé à une unité ; constant sous les hypothèses usuelles.

  3. term

    Coût mixte

    meaning

    Somme d’une composante fixe et d’une composante variable.

  4. term

    Segment significatif

    meaning

    Zone de volumes où la structure de coûts supposée reste valide.

  5. term

    Coût marginal

    meaning

    Variation du coût total liée à une unité additionnelle.

formulas

  1. name

    Coût total

    expression

    CT = CF + cv × Q

    when

    Prévoir le coût dans une même structure et un même segment.

    symbols

    1. symbol

      CT

      meaning

      coût total, $

    2. symbol

      CF

      meaning

      coûts fixes totaux, $

    3. symbol

      cv

      coût variable par unité, $/u

  2. name

    Coût moyen

    expression

    CM = CT / Q = CF/Q + cv

    when

    Comparer le coût par unité sans le confondre avec le coût incrémental.

    symbols

    1. symbol

      CM

      meaning

      coût total moyen par unité

    2. symbol

      Q

      meaning

      volume, strictement positif

workedExamples

  1. title

    Quarante ou quatre-vingts sandwichs — exemple original

    prompt

    Le local coûte 120 $ par jour et chaque sandwich 3 $ de coûts variables. Calcule CT et coût moyen pour 40 puis 80 sandwichs.

    steps

    1. Pour 40 : CT = 120 + 3×40 = 240 $ ; CM = 240/40 = 6 $.

    2. Pour 80 : CT = 120 + 3×80 = 360 $ ; CM = 360/80 = 4,50 $.

    3. Le local coûte toujours 120 $. Sa part par unité passe de 3 $ à 1,50 $.

    answer

    CT 240 $ puis 360 $ ; CM 6 $ puis 4,50 $.

    pitfall

    Croire que doubler la production double le loyer.

  2. title

    Au-delà du palier — exemple original

    prompt

    Une machine permet 100 unités par jour. CF = 200 $, cv = 4 $. À partir de 101 unités, louer une seconde machine ajoute 100 $ fixes. Quel CT pour 100 et 101 unités ?

    steps

    1. À 100 : CT = 200 + 4×100 = 600 $.

    2. À 101 : nouvelle structure CF = 300 $ ; CT = 300 + 4×101 = 704 $.

    3. La 101 e unité ajoute 104 $, dont 100 $ de nouveau palier.

    answer

    600 $ puis 704 $ ; coût marginal de la 101 e unité = 104 $.

    pitfall

    Appliquer aveuglément 200 + 4 Q après la limite de capacité.

  3. title

    La dernière place dans un atelier — exemple original

    prompt

    CF 1 000 $, cv 4 $/unité, capacité du premier atelier 100 unités. À la 101e unité, une extension ajoute 500 $ de CF.

    steps

    1. CT à 100 = 1 000 + 4×100 = 1 400 $.

    2. CT à 101 = 1 000 + 500 + 4×101 = 1 904 $.

    3. Coût marginal de la 101e = 1 904 − 1 400 = 504 $.

    4. Les 500 $ du palier expliquent l'écart; cv reste 4 $ dans les segments considérés.

    answer

    504 $ pour l'unité qui déclenche le palier.

    pitfall

    Répondre 4 $ sans vérifier la capacité.

recall

  1. prompt

    Que devient le coût fixe par unité si le volume double ?

    answer

    Il est divisé par deux si le coût fixe total reste inchangé.

    hint

    CF/Q.

    id

    compta-fixes-variables-r1

  2. prompt

    Que devient le coût variable total si le volume double ?

    answer

    Il double si cv reste constant.

    hint

    cv×Q.

    id

    compta-fixes-variables-r2

  3. prompt

    Un coût fixe est-il toujours non pertinent à une décision ?

    answer

    Non : un nouveau palier ou un coût fixe spécifique évitable peut être pertinent.

    hint

    La question est : change-t-il ?

    id

    compta-fixes-variables-r3

  4. prompt

    Pourquoi peut-on vendre sous le coût moyen sans perdre sur l’ajout ?

    answer

    Parce que le coût moyen inclut des coûts fixes déjà engagés ; il faut comparer le revenu additionnel aux coûts pertinents et à la capacité.

    hint

    Coût marginal, puis capacité.

    id

    compta-fixes-variables-r4
