phase

both

prerequisites

  1. compta-pertinence

analogy

Ton four peut faire dix pizzas et huit sont déjà vendues au prix normal. Une nouvelle commande de quatre pizzas utilise deux places libres et prend deux places de clients habituels. Son prix doit compenser ce que ces clients auraient rapporté.

explanation

  1. Commence toujours par la capacité : capacité totale moins usage régulier = capacité libre. Compare la demande de la commande spéciale à cette disponibilité, dans la même unité de ressource : produits, heures-machine ou heures de MOD.

  2. À capacité libre, calcule les coûts variables spécifiques à la commande et les coûts fixes additionnels. Les commissions habituelles peuvent être supprimées ou modifiées : lire le cas au lieu de recopier le coût régulier.

  3. Si la capacité manque et qu’on sacrifie des ventes régulières, le coût de renonciation correspond à la MCV perdue, pas au prix de vente perdu entier. Les coûts variables réguliers seront aussi économisés.

  4. Le prix minimum total couvre coûts variables de la commande + coûts fixes spécifiques + coût de renonciation. Divise par le nombre d’unités de la commande pour obtenir le prix unitaire. Le résultat différentiel au prix proposé est le revenu moins ces coûts.

  5. Si une capacité supplémentaire est achetée, utilise son coût et vérifie les paliers. Ne cumule pas automatiquement capacité additionnelle et renonciation si l’un remplace l’autre. Les heures supplémentaires modifient la MOD des seules heures concernées.

  6. Le prix minimum est un plancher financier dans les hypothèses, pas une bonne politique tarifaire à long terme. Ajoute des facteurs précis : fidélité des clients évincés, capacité des fournisseurs, qualité, santé, délais et paiement du nouveau client. Les notes indiquent normalement pas d’économies d’échelle dans la simplification du cours ; si un énoncé en donne explicitement, les traiter une seule fois.

workedExamples

  1. title

    Capacité libre — exemple original

    prompt

    Capacité 500 gourdes ; clients réguliers 300 ; commande de 100 à 12 $ ; cv spécial 7 $, coût fixe de logo 200 $.

    steps

    1. Capacité libre = 500−300=200 ; 100 nécessaires : pas de renonciation.

    2. MCV spéciale = (12−7)×100 = 500 $.

    3. ΔR=500−200=300 $.

    4. Prix minimum = (700+200)/100=9 $.

    answer

    Gain 300 $ ; prix minimum 9 $.

    pitfall

    Retrancher les CF déjà présents dans l’entreprise sans changement.

  2. title

    Capacité saturée — exemple original

    prompt

    100 chambres ; 80 régulières à 100 $ avec cv 35 $. Groupe de 25 à 80 $, même cv, aucun coût fixe nouveau.

    steps

    1. Besoin 80+25=105 ; il faut renoncer à 5 clients réguliers.

    2. MCV régulière = 100−35=65 $. CR=5×65=325 $.

    3. MCV spéciale = 25×(80−35)=1 125 $.

    4. ΔR=1 125−325=800 $.

    5. pmin=(25×35+325)/25=48 $. Vérifier le risque de perdre définitivement les clients.

    answer

    Gain 800 $ pour la période ; plancher financier 48 $ par chambre.

    pitfall

    Utiliser 5×100 comme coût de renonciation : cela oublie les dépenses variables évitées.

    Pourquoi recalculer cv de la commande spéciale ?

    answer

    Lire les conditions.

  4. prompt

    Au prix minimum, quel est le ΔR ?

    answer

    Zéro sous les hypothèses : on couvre exactement les coûts pertinents.

    hint

    Plancher, pas marge de négociation.

    Non : une extension de capacité peut éviter la renonciation ; comparer les scénarios explicitement.

    Alternatives plutôt qu’automatismes.
