prerequisites

analogy

Comme un détective : tu précises ce que tu veux savoir, réutilises les preuves déjà disponibles, puis récoltes seulement celles qui manquent.

explanation

  1. Un système d’information marketing (SIM) réunit données internes, intelligence marketing et recherche pour soutenir analyse, planification, mise en œuvre et contrôle. Il fonctionne en continu; un sondage unique n’est pas tout le SIM.

  2. Données secondaires : elles existent déjà et ont été collectées auparavant pour une autre fin. Elles peuvent être internes ou externes. Données primaires : tu les collectes spécifiquement pour ta question actuelle. Le fait qu’une donnée soit sur Internet ne la classe pas automatiquement comme secondaire; regarde pourquoi et comment elle a été produite.

  3. Exploratoire = clarifier un problème ou découvrir des idées; descriptive = décrire précisément un phénomène; causale = tester une relation de cause par un dispositif contrôlé. Qualitatif vise sens et profondeur; quantitatif vise mesure structurée. Une association observée ne prouve pas une cause.

  4. Le processus part d’un problème marketing, formule le problème de recherche, choisit une méthodologie, construit/teste les instruments, collecte, analyse et communique résultats/recommandations. Ne rédige pas un sondage avant de savoir quelle décision il devra éclairer.

  5. Évalue une source avec qui, but, profil, date et méthode. Une information utile est pertinente, fiable et assez complète. Pour un échantillon, distingue population cible, unité interrogée, méthode de sélection et taille. Un grand échantillon mal choisi peut rester biaisé.

vocabulary

  1. term

    SIM

    meaning

    Ressources et procédures transformant données internes/externes en information utile à la décision.

  2. term

    Données primaires

    meaning

    Données originales collectées pour la question de recherche actuelle.

  3. term

    Données secondaires

    meaning

    Données déjà disponibles et réutilisées pour la recherche.

  4. term

    Exploratoire

    meaning

    Recherche pour clarifier un problème ou explorer des pistes.

  5. term

    Descriptive

    meaning

    Recherche pour décrire un phénomène et ses caractéristiques.

  6. term

    Causale

    meaning

    Recherche qui teste un lien de cause à effet avec contrôle approprié.

  7. term

    Population cible

    meaning

    Ensemble concerné par l’étude.

  8. term

    Unité d’échantillonnage

    meaning

    Entité sélectionnée ou interrogée pour produire les données.

formulas

    workedExamples

    1. title

      Le prix du sandwich

      prompt

      Le café veut savoir si passer le prix de 6 $ à 5 $ augmente les achats. Il possède déjà les ventes passées et peut organiser un test.

      steps

      1. Question managériale : faut-il baisser le prix?

      2. Question de recherche : quel est l’effet du prix sur achats et contribution, à conditions comparables?

      3. Les ventes déjà enregistrées sont secondaires pour cette étude.

      4. Un test organisé pour la question produit des données primaires.

      5. Contrôler horaire, menu et fréquentation pour interpréter un effet du prix.

      answer

      Une étude causale vise l’effet, une étude descriptive pourrait seulement décrire les ventes.

      pitfall

      Conclure que le prix cause une hausse parce que le jeudi vend plus que le lundi; d’autres facteurs changent.

    questions

    1. id

      marketing-recherche-sim-qcm-1

      type

      mcq

      prompt

      Un rapport de ventes déjà présent dans l’entreprise est réutilisé pour une nouvelle étude. C’est :

      options

      1. Une expérience causale automatique

      2. Une donnée primaire obligatoire

      3. Une donnée secondaire interne

      4. Une donnée secondaire externe

      correctIndex

      2

      solution

      La donnée existait avant le mandat actuel et vient de l’organisation : secondaire interne.

    2. id

      marketing-recherche-sim-qcm-2

      type

      mcq

      prompt

      Dix entretiens cherchent à découvrir pourquoi les clients quittent. L’intention est surtout :

      options

      1. Exploratoire

      2. Causale contrôlée

      3. Un recensement exhaustif

      4. La preuve d’un pourcentage de population

      correctIndex

      0

      solution

      Les entretiens explorent les raisons et aident à formuler des hypothèses. Dix entretiens ne donnent pas à eux seuls une fréquence représentative.

    3. id

      marketing-recherche-sim-qcm-3

      type

      mcq

      prompt

      On compare deux groupes similaires avec une seule variation contrôlée de prix. Quel objectif de recherche correspond?

      options

      1. Simplement archivistique

      2. Uniquement psychographique

      3. Aucun objectif possible

      4. Causal

      correctIndex

      3

      solution

      Le dispositif cherche à isoler l’effet du prix. L’interprétation dépend encore de la qualité de contrôle et de sélection des groupes.

    4. id

      marketing-recherche-sim-application-1

      type

      open

      prompt

      Des ventes chutent. Propose une question managériale, une question de recherche et deux sources à consulter avant un sondage.

      solution

      Question managériale : quelles actions corrigeront la baisse? Question de recherche : la baisse vient-elle d’une disponibilité réduite, d’une perte de clients ou d’un changement d’achat? Consulter les ventes/ruptures internes et des informations de marché/concurrence déjà disponibles. Ensuite collecter les données manquantes.

      rubric

      1. Distinguer décision à prendre et information à obtenir.

      2. Nommer une source interne et une externe avec leur utilité.

      3. Éviter de confondre corrélation et cause.

    5. id

      marketing-recherche-sim-transfert-1

      type

      mcq

      prompt

      Une étude déjà publiée est réutilisée pour votre nouveau mandat. Ces données sont :

      options

      1. Secondaires pour ce mandat

      2. Primaires parce que vous les lisez pour la première fois

      3. Causales par définition

      4. Nécessairement internes

      correctIndex

      0

      solution

      La classification primaire/secondaire dépend de la collecte pour le mandat actuel. L’origine interne/externe constitue un autre axe.

    6. id

      marketing-recherche-sim-transfert-2

      type

      mcq

      prompt

      Le revenu et la satisfaction augmentent ensemble dans un sondage. Quelle conclusion est soutenue sans protocole causal?

      options

      1. L’absence totale de relation

      2. Une association observée, sans causalité démontrée

      3. Le revenu cause nécessairement la satisfaction

      4. La satisfaction cause nécessairement le revenu

      correctIndex

      1

      solution

      La variation conjointe ne distingue pas direction causale et autres variables. Une conclusion causale exige davantage de preuves.

    masteryChecklist

    1. Choisir exploratoire, descriptive ou causale en justifiant.

    2. Classer données selon origine et usage actuel.

    3. Évaluer une source avant de l’utiliser.

    4. Reconstituer les étapes de recherche et les quatre décisions d’échantillonnage.
