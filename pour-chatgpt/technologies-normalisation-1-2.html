prerequisites

  1. technologies-tables-cles

analogy

Une boîte contenant chaussettes, crayons et bonbons est difficile à chercher. Tu commences par séparer les objets ; ensuite, tu ranges chaque information dans la boîte où elle dépend vraiment du bon identifiant.

explanation

  1. La normalisation organise des données pour éviter répétitions inutiles et incohérences. Partir d’un formulaire ou d’une facture permet d’identifier attributs, clés et dépendances avant de construire les tables.

  2. Première forme normale (1FN) : une clé et des valeurs atomiques selon le domaine. Un champ contenant «pizza, boisson, dessert» représente plusieurs articles. Une ligne de détail par article rend la quantité et le prix manipulables.

  3. Une dépendance fonctionnelle X→Y signifie qu’une valeur de X détermine une seule valeur de Y dans les règles du modèle. Le noClient détermine le nom du client ; le nom peut ne pas déterminer noClient.

  4. Deuxième forme normale (2FN) : 1FN et chaque attribut non clé dépend de la clé dans son intégrité. Avec clé composée(noCommande, noArticle), la dateCommande dépend seulement de noCommande ; nomArticle seulement de noArticle. Les déplacer dans leurs tables respectives.

  5. Les attributs du lien, comme quantité commandée, dépendent du couple complet. Une clé primaire artificielle seule ne supprime pas magiquement les dépendances sémantiques et les anomalies : il faut examiner les règles et clés candidates.

  6. Après séparation, conserver les liens nécessaires. La normalisation ne signifie pas perdre des données ou supprimer toute répétition de référence ; les clés étrangères relient les entités.

vocabulary

  1. term

    Valeur atomique

    meaning

    Valeur traitée comme une unité dans son domaine, sans liste de plusieurs objets dans la même cellule.

  2. term

    Dépendance fonctionnelle

    meaning

    X détermine une valeur de Y selon les règles du modèle.

  3. term

    Clé composée

    meaning

    Identifiant constitué de plusieurs attributs.

  4. term

    Dépendance partielle

    meaning

    Attribut dépendant d’une partie d’une clé composée.

  5. term

    Anomalie

    meaning

    Erreur de mise à jour, ajout ou suppression liée à une mauvaise structure.

formulas

    workedExamples

    1. title

      Première forme normale — exemple original

      prompt

      Commande 10 : articles «livreA×2, styloB×3». Comment rendre les lignes exploitables ?

      steps

      1. Séparer les types d’articles en lignes de détail.

      2. (commande 10,articleA, quantité 2) et (commande 10,articleB, quantité 3).

      3. Définir une clé de détail adaptée aux règles : couple commande/article si chaque article n’apparaît qu’une fois, sinon numéro de ligne.

      4. Les quantités deviennent numériques et indépendantes.

      answer

      Deux lignes atomiques reliées à la commande 10.

      pitfall

      Créer des colonnes Article 1,Article 2,Article 3 sans règle extensible.

    2. title

      Deuxième forme normale — exemple original

      prompt

      TableDetail(noCommande, noArticle, dateCommande, nomArticle, quantité), clé(noCommande, noArticle). Quelles séparations ?

      steps

      1. noCommande→dateCommande : table Commande.

      2. noArticle→nomArticle : table Article.

      3. Couple(noCommande, noArticle)→quantité : garder dansDetail.

      4. Detail référence Commande et Article.

      answer

      Commande(noCommande, date) ; Article(noArticle, nom) ; Detail(noCommande, noArticle, quantité).

      pitfall

      Laisser date et nom répétés pour chaque combinaison sans examiner leurs dépendances.

    recall

    1. prompt

      Condition de 1FN ?

      answer

      Clé et attributs atomiques dans le domaine.

      hint

      Pas une liste d’articles dans une cellule.

      id

    2. prompt

      Que dit X→Y ?

      answer

      Une valeur de X détermine une seule valeur de Y selon la règle.

      hint

      Détermination, pas simple corrélation.

      id

      technologies-normalisation-1-2-r2

    3. prompt

      Ce que 2FN retire ?

      answer

      Les dépendances à une partie d’une clé composée.

      hint

      La clé entière.

      id

      technologies-normalisation-1-2-r3

    4. prompt

      Pourquoi quantité reste dans Detail ?

      answer

      Elle dépend de l’article dans cette commande, donc du lien complet.

      hint

      Le même article se commande différemment selon le client.

      technologies-normalisation-1-2-r4

      mcq

      prompt

      Clé(noCommande, noArticle) ; nomArticle dépend de noArticle seulement. C’est…

      options

      1. toujours une donnée impossible

      2. une mesure de sécurité

      3. une dépendance partielle

      4. une absence de clé

      correctIndex

      2

      solution

      Le nom ne dépend pas du couple complet ; il appartient à Article.

      mcq

      prompt

      Une cellule «2 livres;3 stylos» est problématique surtout pour…

      options

      1. le sommeil

      2. l’ERP uniquement

      3. 1FN

      4. le prix de vente

      correctIndex

      2

      solution

      Elle regroupe plusieurs objets et quantités dans un champ.

    3. type

      open

      prompt

      Propose les tables d’une facture avec client, lignes articles et quantité.

      solution

      Client avec ses attributs ; Facture avec date et référence client ; Article avec libellé actuel ; Ligne avec références facture/article et quantité, prix vendu si nécessaire.

      rubric

      1. Entités séparées.

      2. Clés identifiées.

      3. Liens conservés.

      4. Quantité attribuée au détail.

      id

      technologies-normalisation-1-2-q3

    4. type

      open

      prompt

      Table Ligne(noCommande, noArticle, nomArticle, quantité). Clé composite des deux numéros. Quelle dépendance partielle ?

      solution

      nomArticle dépend seulement de noArticle ; isoler Article(noArticle, nomArticle). quantité décrit la ligne et reste avec la clé composite.

      rubric

      1. Clé composite reconnue.

      2. Dépendance nomArticle.

      3. Table Article.

      4. Quantité reste ligne.

      id

      technologies-normalisation-1-2-q4
