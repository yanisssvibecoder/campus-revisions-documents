prerequisites

analogy

Une règle mesure une longueur ; une balance mesure une masse. Un graphique se choisit de la même façon : pour la question et les données, pas parce qu’il paraît joli.

explanation

  1. Comparer des catégories : barres, avec axe et ordre lisibles. Suivre une évolution chronologique : ligne, avec périodes ordonnées. Examiner une distribution quantitative : histogramme ; examiner la dispersion et les valeurs extrêmes : boîte à moustaches selon ce qui a été enseigné.

  2. Explorer une relation entre deux variables quantitatives : nuage de points. Une relation visible ne prouve pas la causalité : une troisième variable ou la structure des données peut expliquer l’association.

  3. Un diagramme en secteurs convient seulement à un ensemble de parts d’un même total et à peu de catégories faciles à distinguer. Il convient mal aux comparaisons fines, aux nombreuses catégories, aux valeurs négatives et aux totaux qui ne représentent pas la même population.

  4. La couleur peut distinguer catégories ou indiquer intensité/alerte ; garder une convention cohérente. Ne pas exiger de distinguer rouge et vert sans autre signal. Une légende, un libellé ou un symbole doit préserver la compréhension.

  5. Pour des barres comparant des magnitudes, un axe tronqué peut exagérer les différences ; partir de zéro donne une lecture honnête des longueurs. Pour une courbe, une autre plage peut être utile, mais l’échelle doit être explicite et le commentaire proportionné.

  6. Chaque vue précise titre questionnel, unité, période, filtres et source/actualisation. Éviter 3 D décorative, surcharge et éléments sans valeur informative. Faire ressortir la comparaison essentielle avant de multiplier détails.

  7. Dans Tableau Desktop, vérifier si le champ est utilisé comme dimension ou mesure, s’il est discret ou continu, et quelle agrégation est appliquée. Une date peut produire des catégories ou une chronologie continue ; le choix dépend de la question. Les démonstrations du cours donnent les gestes de l’outil.

vocabulary

  1. term

    Catégorie

    meaning

    Groupe qualitatif de comparaison.

  2. term

    Continu

    meaning

    Valeur sur un continuum, comme le temps ou une mesure.

  3. term

    Histogramme

    meaning

    Fréquence d’observations dans des intervalles quantitatifs.

  4. term

    Nuage de points

    meaning

    Position de chaque observation selon deux valeurs quantitatives.

  5. term

    Corrélation

    meaning

    Association observée entre des variables.

  6. term

    Échelle

    meaning

    Correspondance entre valeurs et positions/longueurs graphiques.

formulas

    workedExamples

    1. title

      Question avant forme — exemple original

      prompt

      Questions : ventes par région ; ventes par semaine ; relation prix/quantité.

      steps

      1. Régions distinctes : barres pour comparer les montants.

      2. Semaines ordonnées : courbe pour voir l’évolution.

      3. Prix et quantité par observation : nuage pour examiner la relation.

      4. Dans les trois cas, définir même périmètre, unités et filtres avant de conclure.

      answer

      Barres, courbe et nuage répondent à trois besoins distincts.

      pitfall

      Utiliser le même graphique pour toutes les questions.

    2. title

      Une barre trompeuse — exemple original

      prompt

      Valeurs A=100 et B=110. L’axe commence à 95 ; hauteurs visibles 5 et 15.

      steps

      1. Différence réelle : 10, soit 10 % de 100.

      2. Le dessin tronqué fait paraître B trois fois plus haut.

      3. Avec axe zéro, les longueurs 100 et 110 montrent une différence proportionnée.

      4. Indiquer différence réelle et échelle ; ne pas déduire ratio des hauteurs tronquées.

      answer

      B dépasse A de 10 %, pas de 200 %.

      pitfall

      Prendre le ratio des hauteurs visibles comme ratio des valeurs réelles.

    questions

    1. type

      mcq

      prompt

      Comparer les ventes de six régions à la même période : choisir surtout…

      options

      1. barres

      2. secteurs 3 D nécessaires

      3. une liste de mots aléatoires

      4. une courbe reliant arbitrairement les régions

      correctIndex

      0

      solution

      Les barres facilitent les comparaisons de catégories.

      id

      technologies-graphiques-q1

    2. type

      mcq

      prompt

      Prix et quantité sont associés dans un nuage. On peut conclure…

      options

      1. que tous les stocks sont exacts

      2. une association observée, à examiner

      3. que le prix cause forcément toute variation

      4. que la base est en 3FN

      correctIndex

      1

      solution

      L’association seule ne démontre pas le mécanisme causal.

      id

      technologies-graphiques-q2

    3. type

      number

      prompt

      A=80, B=100. Hausse de B par rapport à A en % ?

      correctNumber

      25

      tolerance

      0.01

      units

      %

      solution

      (100−80)/80×100=25 %.

      id

      technologies-graphiques-q3

    4. type

      open

      prompt

      Choisis un graphique pour les délais de 200 commandes et explique.

      solution

      Histogramme pour la répartition par intervalles ; boîte à moustaches pour médiane/dispersion et valeurs extrêmes si souhaité. Indiquer unités, période et population ; une moyenne seule peut cacher des retards extrêmes.

      rubric

      1. Distribution pertinente.

      2. Unité/période.

      3. Dispersion ou extrêmes.

      4. Limite de moyenne seule.

      id

      technologies-graphiques-q4

    masteryChecklist

    1. Je justifie le graphique par la question.

    2. Je repère une échelle ou agrégation trompeuse.

    3. Je décris un résultat sans inventer une causalité.
