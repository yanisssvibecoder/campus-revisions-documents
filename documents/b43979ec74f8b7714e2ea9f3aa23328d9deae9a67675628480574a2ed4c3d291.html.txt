<section id="calculatrice">
  <h2>🧮 Module 1 — La calculatrice BA II Plus pour débutant total</h2>
  <p><b>Pourquoi c'est le module 1 :</b> au quiz, la calculatrice est ton outil de vitesse. Pour trouver un <b>taux de rendement à l'échéance (RAE/TRE)</b> d'une obligation, elle est même <b>obligatoire</b> (essai-erreur à la main = trop long, la prof le confirme dans la FAQ). Mais souviens-toi : <b>la calculatrice trouve le chiffre, ta plume écrit la formule.</b></p>

  <div class="encadre"><b>🖩 SI TU UTILISES UNE SHARP EL-733A (calculatrice physique) :</b> tout marche pareil avec cette traduction : <b>2ND → 2ndf</b> · <b>2ND CLR TVM → 2ndf + CA</b> (CA = Clear All, en orange au-dessus d'une touche d'effacement — vérifie avec le test : tape <code>99 N</code>, <code>2ndf CA</code>, <code>RCL N</code> → doit afficher 0) · <b>I/Y → i</b> · <b>CPT → COMP</b> · <b>+/− → +/−</b>. N, PV, PMT, FV sont identiques. ⚠️ <b>CA efface AUSSI les mémoires</b> : écris tes taux périodiques sur papier (6+ décimales) au lieu de les stocker. Pas de P/Y à gérer (le cours travaille au taux périodique manuel de toute façon). Toutes les séquences de ce plan se lisent alors : remplace simplement I/Y par i et CPT par COMP.</div>

  <h3>1.1 Ton clavier décrypté (seulement ce qui compte)</h3>
  <table>
    <tr><th>Touche</th><th>Nom</th><th>À quoi ça sert</th></tr>
    <tr><td><b>2ND</b> (&amp;)</td><td>Seconde fonction</td><td>Active la petite fonction écrite <u>au-dessus</u> d'une touche (ex. <b>2ND CLR TVM</b> au-dessus de FV).</td></tr>
    <tr><td><b>N</b></td><td>Nombre de périodes</td><td>Combien de versements/périodes AU TOTAL.</td></tr>
    <tr><td><b>I/Y</b></td><td>Taux par période</td><td>Le taux <b>périodique</b> (celui qui matche la période de tes versements).</td></tr>
    <tr><td><b>PV</b></td><td>Valeur actuelle</td><td>Montant au début (aujourd'hui). Tu l'entres en <b>négatif</b> si c'est toi qui paies.</td></tr>
    <tr><td><b>PMT</b></td><td>Versement</td><td>Le montant récurrent ÉGAL (annuité).</td></tr>
    <tr><td><b>FV</b></td><td>Valeur future</td><td>Montant à la fin.</td></tr>
    <tr><td><b>CPT</b> (%)</td><td>Compute</td><td>« Calcule-moi la case vide » — tu appuies dessus PUIS la touche cherchée.</td></tr>
    <tr><td><b>2ND CLR TVM</b></td><td>Effacer TVM</td><td>Remet N, I/Y, PV, PMT, FV à zéro. <b>À faire avant CHAQUE problème.</b></td></tr>
  </table>
  <div class="danger"><b>🚨 La convention des signes (l'erreur #1 des débutants) :</b> la calculatrice voit l'argent comme des flux : ce qui <b>sort de ta poche = négatif</b>, ce qui <b>entre dans ta poche = positif</b>. Un seul signe par problème, sinon « Error 5 ». Ex. tu places −1 000 (sortie) aujourd'hui pour recevoir +1 500 (entrée) plus tard.</div>

  <h3>1.2 Réglages à faire UNE fois</h3>
  <h4>Nombre de décimales (4 suffit, 8 pour vérifier)</h4>
  <div class="seq"><span class="touche">2ND</span> . (le point = FORMAT) → tape <span class="touche">4</span> → <span class="touche">ENTER</span> → <span class="touche">2ND</span> <span class="touche">CPT</span> (QUIT)  <br>→ l'écran affichera DEC = 4.0000. La prof exige de la précision : garde le maximum de décimales dans tes calculs intermédiaires (utilise la touche <b>STO 1</b> pour mémoriser un résultat, <b>RCL 1</b> pour le rappeler).</div>

  <h3>1.3 L'approche du cours : le taux périodique MANUEL</h3>
  <div class="encadre">Le guide BA II Plus du cours (dans ton dossier ZoneCours) utilise la méthode suivante, et c'est celle-ci que tu dois maîtriser : <b>tu calcules TOI-MÊME le taux périodique</b> (aligné sur la fréquence des versements), puis tu le mets dans I/Y. Pas de magie P/Y : tu gardes le contrôle. (Si tu connais déjà P/Y, tu peux l'utiliser, mais l'approche manuelle colle aux démarches écrites exigées.)</div>

  <h3>1.4 Les 5 gestes de base — avec exemples complets</h3>

  <h4>Geste A — Montant simple : capitaliser (VA → VC)</h4>
  <div class="exemple"><div class="titre-ex">1 000 $ placés 2 ans à 3 % nominal capitalisation semestrielle. VC = ?</div>
    Taux semestriel : 3 %/2 = 1,5 %. Périodes : 2 ans × 2 = 4 semestres.<br>
    Formule à écrire : VC = 1 000 × (1,015)<sup>4</sup> = <b>1 061,36 $</b>
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 4 <span class="touche">N</span> · 1.5 <span class="touche">I/Y</span> · 1000 <span class="touche">+/−</span> <span class="touche">PV</span> · 0 <span class="touche">PMT</span> · <span class="touche">CPT</span> <span class="touche">FV</span> → 1 061,3636</div>
  </div>

  <h4>Geste B — Montant simple : actualiser (VC → VA)</h4>
  <div class="exemple"><div class="titre-ex">1 000 $ à recevoir dans 1 an, taux nominal 6 % capitalisation mensuelle. VA = ?</div>
    Taux mensuel : 0,5 %. Périodes : 12 mois.<br>
    Formule : VA = 1 000 × (1,005)<sup>−12</sup> = <b>941,91 $</b>
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 12 <span class="touche">N</span> · 0.5 <span class="touche">I/Y</span> · 0 <span class="touche">PV</span> · 0 <span class="touche">PMT</span> · 1000 <span class="touche">FV</span> · <span class="touche">CPT</span> <span class="touche">PV</span> → −941,9053 (le signe est une convention d'entrée/sortie)</div>
  </div>

  <h4>Geste C — Conversion de taux (l'arme secrète)</h4>
  <div class="exemple"><div class="titre-ex">Quel est le taux mensuel équivalent à un taux effectif de 6 % ?</div>
    Formule : (1 + i<sub>eff</sub>) = (1 + i<sub>mens</sub>)<sup>12</sup> → i<sub>mens</sub> = (1,06)<sup>1/12</sup> − 1 = <b>0,486755 % par mois</b>
    <div class="seq">1.06 <span class="touche">y^x</span> ( 1 ÷ 12 ) <span class="touche">=</span> → 1.0048675 · <span class="touche">−</span> 1 <span class="touche">=</span> → 0.0048675</div>
  </div>

  <h4>Geste D — Annuité : VAA et VFA</h4>
  <div class="exemple"><div class="titre-ex">12 versements mensuels de 100 $, taux effectif 6 % (donc i<sub>mens</sub> = 0,486755 %, calculé au Geste C). Valeur acquise au dernier versement ?</div>
    Formule : VFA = PMT × [(1+i)<sup>n</sup> − 1]/i = 100 × [(1,0048675)<sup>12</sup> − 1]/0,0048675 = <b>1 232,71 $</b> <span class="cle">(valeur affichée par le guide du cours; le calcul exact sans arrondir le taux donne 1 232,65 $ — l'écart vient de l'arrondi du taux dans le guide)</span>
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 12 <span class="touche">N</span> · 0.486755 <span class="touche">I/Y</span> · 0 <span class="touche">PV</span> · 100 <span class="touche">+/−</span> <span class="touche">PMT</span> · <span class="touche">CPT</span> <span class="touche">FV</span> → 1 232.7070</div>
  </div>

  <h4>Geste E — Obligation : prix (PV) et RAE (I/Y)</h4>
  <div class="exemple"><div class="titre-ex">VN 1 000 $, coupon 5 % (25 $ semestriel), 12 ans (24 périodes), TRE 8 % (4 % sem.). Prix ?</div>
    Formule : P = 25 × [1 − (1,04)<sup>−24</sup>]/0,04 + 1 000 × (1,04)<sup>−24</sup> = <b>771,30 $</b>
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 24 <span class="touche">N</span> · 4 <span class="touche">I/Y</span> · 25 <span class="touche">PMT</span> · 1000 <span class="touche">FV</span> · <span class="touche">CPT</span> <span class="touche">PV</span> → −771.30</div>
  </div>
  <div class="exemple"><div class="titre-ex">Même obligation achetée 1 040 $. RAE nominal ?</div>
    On cherche le taux semestriel i tel que 1 040 = 25 × [1−(1+i)<sup>−24</sup>]/i + 1000(1+i)<sup>−24</sup>. La calculatrice le trouve par itération :
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 24 <span class="touche">N</span> · 1040 <span class="touche">+/−</span> <span class="touche">PV</span> · 25 <span class="touche">PMT</span> · 1000 <span class="touche">FV</span> · <span class="touche">CPT</span> <span class="touche">I/Y</span> → ≈ 2,526 (% semestriel) × 2 = <b>≈ 5,05 % nominal sem.</b></div>
    (C'est le seul calcul réellement IMPOSSIBLE à faire à la main dans un temps raisonnable — d'où la calculatrice obligatoire.)
  </div>

  <h3>1.5 Les pièges qui coûtent des points</h3>
  <ul>
    <li><b>Begin/End :</b> si le premier versement est <b>immédiat (début de période)</b>, calcule l'annuité normale (fin) puis <b>multiplie par (1+i)</b>. C'est l'approche du cours (plus simple que le mode BGN de la calculatrice).</li>
    <li><b>Oublier 2ND CLR TVM</b> entre deux problèmes → les vieux N/PV contaminent le calcul.</li>
    <li><b>I/Y est un POURCENTAGE</b> : tu entres 4.5 pour 4,5 % (pas 0.045). Mais dans les formules écrites, tu utilises 0,045.</li>
    <li><b>N doit matcher la période de I/Y</b> : mois avec mois, semestres avec semestres.</li>
    <li><b>Precision :</b> convertis les taux avec un maximum de décimales (STO/RCL), arrondis seulement à la fin.</li>
  </ul>
  <div class="retiens"><b>À retenir :</b> 2ND CLR TVM → N, I/Y (périodique!), PV, PMT, FV → CPT. Signes cohérents. Début de période = ×(1+i). Pour le RAE d'une obligation : N, ±PV, PMT (coupon), FV (VN) → CPT I/Y, puis ×2 (nominal semestriel).</div>

<section id="mathfin">
  <h2>💰 Module 3 — Séances 1-2 : Mathématiques financières (LE cœur du quiz)</h2>
  <p><b>La phrase qui résume tout le cours :</b> <i>« Un dollar gagné aujourd'hui vaut plus qu'un dollar gagné demain. »</i> Pourquoi? Parce que ton dollar d'aujourd'hui peut <b>gagner des intérêts</b> en attendant. Toute la finance de ce quiz découle de cette seule idée.</p>

  <h3>3.1 Intérêt simple vs intérêt composé (la base de la base)</h3>
  <div class="exemple"><div class="titre-ex">Tu prêtes 100 $ à 10 % par année, pendant 2 ans.</div>
    <b>Intérêt simple</b> (les intérêts ne rapportent rien) : 100 + 10 + 10 = <b>120 $</b><br>
    <b>Intérêt composé</b> (les intérêts rapportent à leur tour des intérêts) : 100 × (1,10)² = <b>121 $</b><br>
    Le 1 $ de différence? C'est <b>10 % du 10 $</b> gagné en année 1. C'est l'« intérêt sur l'intérêt ».<br>
    <b>En finance, on compose TOUJOURS.</b>
  </div>

  <h3>3.2 Le montant simple — LA formule universelle</h3>
  <div class="formule">VA × (1 + r)<sup>t</sup> = VC
    <small>VA = valeur actuelle (aujourd'hui) · VC = valeur capitalisée (future) · r = taux PÉRIODIQUE · t = nombre de périodes</small>
  </div>
  <p>Tout problème de finance se ramène à <b>déplacer un montant dans le temps</b> : <b>capitaliser</b> = aller vers le futur (multiplier); <b>actualiser</b> = revenir vers aujourd'hui (diviser). Le taux d'actualisation tient compte du <b>risque</b> des flux.</p>
  <div class="encadre"><b>La ligne du temps à mémoriser</b> (exemple r = 5 %) : 86,38 (t=−3) · 90,70 (t=−2) · 95,24 (t=−1) · <b>100,00 (aujourd'hui)</b> · 105,00 (t=1) · 110,25 (t=2) · 115,76 (t=3). Remarque : les montants passés sont des actualisations (95,24 × 1,05 = 100).</div>

  <h4>Exercices d'entraînement (exercices des capsules du cours)</h4>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A1</span>Valeur future de 100 $ dans 5 ans à 8 % par année?</div>
    <button class="reveler" data-cible="r-a1">👁 Révéler</button>
    <div id="r-a1" class="cache rep">VC = 100 × (1,08)<sup>5</sup> = <b>146,93 $</b></div>
  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A2</span>Valeur actuelle de 500 $ à recevoir dans 2 ans à 5,5 %?</div>
    <button class="reveler" data-cible="r-a2">👁 Révéler</button>
    <div id="r-a2" class="cache rep">VA = 500 / (1,055)² = <b>449,23 $</b></div>
  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A3</span>Valeur future dans 3 ans d'un montant de 100 000 $ reçu il y a 2 ans à 3 %? <i>(piège : on CAPITALISE sur 5 ans au total)</i></div>
    <button class="reveler" data-cible="r-a3">👁 Révéler</button>
    <div id="r-a3" class="cache rep">VC = 100 000 × (1,03)<sup>5</sup> = <b>115 927,41 $</b> (le « il y a 2 ans » et « dans 3 ans » = 5 périodes de capitalisation au total)</div>
  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A4</span>Dans un an, combien « coûtera » un montant de 700 000 $ à recevoir 22 années plus tard, à 4,5 %? <i>(on actualise de 22 → 1, donc 21 périodes)</i></div>
    <button class="reveler" data-cible="r-a4">👁 Révéler</button>
    <div id="r-a4" class="cache rep">VA<sub>t=1</sub> = 700 000 / (1,045)<sup>21</sup> = <b>277 751,20 $</b> (attention au piège inverse : actualiser de 22 périodes donnerait 265 793 $ — c'est de t=22 à t=1, donc 21 périodes)</div>
  </div>

  <h3>3.3 L'annuité — regrouper des versements ÉGAUX</h3>
  <div class="formule">VAA = PMT × [1 − (1 + r)<sup>−t</sup>] / r &nbsp;&nbsp;&nbsp; VFA = PMT × [(1 + r)<sup>t</sup> − 1] / r
    <small>PMT = versement constant · t = NOMBRE de versements · r = taux périodique (même période que les versements)</small>
  </div>
  <div class="danger"><b>🚨 LA règle d'or (la prof la répète partout) :</b> le résultat d'une annuité (VAA) est <b>TOUJOURS trouvé une période avant le premier versement</b>. Si le premier versement est dans 1 mois, la VAA est « posée » à aujourd'hui. S'il est dans 13 mois, elle est posée au mois 12 — et il faut ensuite l'actualiser pour l'amener à aujourd'hui. <b>Toujours dessiner le schéma temporel avant de calculer!</b></div>
  <div class="encadre"><b>Annuité de DÉBUT de période</b> (premier versement immédiat) : calcule la VAA normale (fin de période) puis <b>multiplie par (1 + r)</b>. Ex. des capsules : un retraité veut 5 000 $/mois (début) pendant 25 ans à 3 % → VAA<sub>fin</sub> × (1 + i<sub>mens</sub>).</div>

  <div class="exemple"><div class="titre-ex"><span class="num-exo">A5</span>Prêt hypothécaire : paiements mensuels de 1 500 $ pendant 25 ans, 3 % nominal capitalisation semestrielle. Valeur du prêt?</div>
    <b>Étape 1 — taux :</b> i<sub>sem</sub> = 1,5 % → i<sub>mens</sub> = (1,015)<sup>2/12</sup> − 1 = 0,24845 % par mois.<br>
    <b>Étape 2 — périodes :</b> 25 × 12 = 300.<br>
    <b>Étape 3 — formule écrite :</b> VAA = 1 500 × [1 − (1,0024845)<sup>−300</sup>]/0,0024845
    <button class="reveler" data-cible="r-a5">👁 Révéler</button>
    <div id="r-a5" class="cache rep">VAA = 1 500 × 211,31 = <b>≈ 316 960 $</b> (arrondi; l'hypothèque canadienne standard = nominal semestriel)</div>
  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A6</span>Vous placez 250 $ aux 2 semaines pendant 3 ans à 2,6 % nominal capitalisation hebdomadaire. Valeur acquise au dernier versement?</div>
    i<sub>hebdo</sub> = 2,6 %/52 = 0,05 % → i<sub>2sem</sub> = (1,0005)² − 1 = 0,100025 %. n = 78.<br>VFA = 250 × [(1,00100025)<sup>78</sup> − 1]/0,00100025
    <button class="reveler" data-cible="r-a6">👁 Révéler</button>
    <div id="r-a6" class="cache rep">VFA = 250 × 81,08 = <b>≈ 20 271 $</b></div>
  </div>

  <h3>3.4 La perpétuité — des versements ÉGAUX à l'infini</h3>
  <div class="formule">VAP = PMT / r
    <small>Le résultat est AUSSI trouvé une période avant le premier versement</small>
  </div>
  <p>S'il n'y a pas d'échéance (rente à vie, action privilégiée), on ne peut pas actualiser chaque flux un à un jusqu'à l'infini. Heureusement : la somme infinie se simplifie en une division. L'analogie : combien dois-je mettre à la banque pour que les intérêts paient exactement le versement, à jamais?</p>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A7</span>Loterie A : 5 M$ immédiatement OU B : 12 500 $/mois à l'infini, à 3 % effectif. Laquelle choisir?</div>
    i<sub>mens</sub> = (1,03)<sup>1/12</sup> − 1 = 0,24663 % → VAP = 12 500/0,0024663
    <button class="reveler" data-cible="r-a7">👁 Révéler</button>
    <div id="r-a7" class="cache rep">VAP = <b>≈ 5 068 000 $</b> → la loterie B (à l'infini) bat légèrement le 5 M$ immédiat. (Si le taux était plus élevé, A gagnerait — c'est le genre de comparaison que le quiz adore.)</div>
  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A8</span>Valeur de CETTE loterie dans 4 semaines? Et dans 5 ans? (la VAP est posée une période avant le 1er versement)</div>
    <button class="reveler" data-cible="r-a8">👁 Révéler</button>
    <div id="r-a8" class="cache rep">La perpétuité « vit » au moment de son calcul : dans 4 semaines, il restera TOUJOURS les mêmes versements à l'infini → même valeur (≈ 5,07 M$, en fait exactement la VAP × (1+i)⁴ si le premier versement reste fixe). <b>Dans 5 ans, valeur = VAP × (1 + i<sub>mens</sub>)<sup>60</sup></b> : une perpétuité capitalise comme un montant simple. Le point clé du cours : <b>une fois regroupés, tous les FMs deviennent UN montant simple</b> qu'on peut déplacer librement dans le temps.</div>
  </div>

  <h3>3.5 L'équivalence de taux — le traducteur de périodes</h3>
  <p><b>Le problème :</b> le taux est « nominal semestriel » mais les paiements sont mensuels. On ne peut PAS diviser par 12! Il faut <b>convertir</b>.</p>
  <table>
    <tr><th>Terme</th><th>Définition simple</th><th>Exemple</th></tr>
    <tr><td><b>Taux nominal</b> (à capitalisation X)<br><small>livre : « taux périodique annuel », « taux spécifié »</small></td><td>Le taux périodique × le nombre de périodes par année (une simple ADDITION des taux périodiques)</td><td>« 12 % nominal semestriel » = 6 % par semestre × 2</td></tr>
    <tr><td><b>Taux effectif</b> (annuel)</td><td>Le vrai rendement d'une année COMPLÈTE, avec capitalisation des intérêts en cours de route</td><td>12 % nominal sem. → (1,06)² − 1 = <b>12,36 % effectif</b></td></tr>
    <tr><td><b>Taux périodique</b></td><td>Le taux d'UNE période de versement — LE SEUL qu'on met dans les formules</td><td>8 % nominal trimestriel → 2 % par trimestre</td></tr>
  </table>
  <div class="formule">(1 + i<sub>1</sub>)<sup>m1</sup> = (1 + i<sub>2</sub>)<sup>m2</sup>
    <small>L'équation magique : chaque côté = le taux EFFECTIF. « L'effort d'une année » est égal des deux côtés.</small>
  </div>
  <div class="encadre"><b>La règle du cours : le taux s'ajuste aux paiements, et non l'inverse.</b> Exemple officiel : 12 % nominal semestriel avec paiements mensuels → (1,06)² = (1 + i<sub>mens</sub>)<sup>12</sup> → i<sub>mens</sub> = 0,9758… %. Autre exemple : 8 % nominal trimestriel avec paiements hebdomadaires → (1,02)⁴ = (1 + i<sub>hebdo</sub>)<sup>52</sup> → i<sub>hebdo</sub> = 0,1524… %.</div>
  <h4>Classement des taux (question classique)</h4>
  <div class="exemple"><div class="titre-ex">Ordonne du plus petit au plus grand : 6 % effectif · 6 % nominal cap. quotidien · 6 % nominal cap. semestriel · 6 % nominal cap. annuelle</div>
    <button class="reveler" data-cible="r-a9">👁 Révéler</button>
    <div id="r-a9" class="cache rep"><b>Annuel (6,00 %) &lt; Semestriel (6,09 %) &lt; Quotidien (≈ 6,18 %) &lt; Effectif… attention!</b> Non — l'effectif de 6 % est simplement 6 % : <b>nominal annuel = effectif = 6,00 %</b> (une seule capitalisation par année). Donc : annuel = effectif (6,00 %) &lt; semestriel (6,09 %) &lt; quotidien (≈ 6,18 %). <b>Plus ça capitalise souvent, plus le vrai rendement est élevé</b> — même taux nominal affiché.</div>
  </div>
  <h4>Exercices de conversion (à faire SANS calculatrice en tête, puis vérifie)</h4>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A10</span>2,6 % nominal cap. hebdomadaire → taux périodique mensuel?</div>
    <button class="reveler" data-cible="r-a10">👁 Révéler</button>

  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A11</span>9 % nominal cap. semestrielle → taux périodique trimestriel?</div>
    <button class="reveler" data-cible="r-a11">👁 Révéler</button>

  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A12</span>5,2 % nominal cap. aux 2 semaines → taux périodique semestriel?</div>

  </div>

  <h3>3.6 Les formules avec croissance (perpétuité et annuité croissantes)</h3>
  <div class="formule">VAP<sub>croissante</sub> = PMT<sub>1</sub> / (r − g) &nbsp;&nbsp;&nbsp;&nbsp; VAAC = PMT<sub>1</sub>/(r−g) × [1 − ((1+g)/(1+r))<sup>t</sup>]
    <small>PMT₁ = premier versement (déjà grown!) · r − g = l'écart rendement/croissance · résultat TOUJOURS une période avant le 1er versement</small>
  </div>
  <div class="attention"><b>⚠️ g doit être UN PÉRIODE PAR PÉRIODE</b> : si les dividendes sont trimestriels, g doit être trimestrique. Et <b>r &gt; g</b> obligatoirement, sinon la formule explose.</div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A13</span>(Exemple du cours) Rente indexée : à 60 ans, premier versement IMMÉDIAT de 7 500 $/mois, indexé 3 % (nominal mensuel : g = 0,25 %/mois), jusqu'à 85 ans (300 mois), rendement 9 % nominal mensuel (i = 0,75 %/mois). Coût?</div>
    VAAC (une période avant le 1er versement — ici le versement est immédiat, donc la formule donne la valeur à t = −1 mois) :<br>
    VAAC = 7 500/(0,0075−0,0025) × [1 − (1,0025/1,0075)<sup>300</sup>] = 7 500/0,005 × [1 − 0,2247] = 1 500 000 × 0,7753
    <button class="reveler" data-cible="r-a13">👁 Révéler</button>
    <div id="r-a13" class="cache rep">VAAC<sub>t=−1</sub> ≈ 1 162 799 $ → on la ramène à aujourd'hui (début de période) : × (1,0075) = <b>≈ 1 171 520 $</b></div>
  </div>

  <h3>3.7 La valeur entre deux dates de versement (méthode officielle en 2 étapes)</h3>
  <div class="encadre"><b>Problème :</b> on est ENTRE deux coupons/dividendes (ex. le dernier coupon remonte à 1 mois, le prochain est dans 5 mois). Méthode du cours (plus rigoureuse que le « clean price » du livre, point 7.5.3 — la prof privilégie CETTE approche) :
  <ol>
    <li><b>Actualiser normalement</b> tous les FMs à la <b>dernière date de versement</b> (l'annuité/perpétuité tombe naturellement une période avant le prochain versement = pile sur cette date);</li>
    <li><b>Capitaliser</b> ce total pour la <b>fraction de période écoulée</b> : × (1 + i)<sup>fraction</sup>.</li>
  </ol></div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A14</span>(Exemple du cours) Le dernier coupon date d'1 mois. Il reste 9 coupons. TC = 8 %, TRE = 5 % (tous deux nominaux semestriels), VN = 1 000 $. Valeur aujourd'hui?</div>
    <b>Étape 1 :</b> i<sub>TRE</sub> = 2,5 %/sem; coupon = 4 % × 1 000 / 2 = 40 $. À la dernière date de coupon (une période avant le prochain coupon) :<br>
    P = 40 × [1 − (1,025)<sup>−9</sup>]/0,025 + 1 000 × (1,025)<sup>−9</sup> = 318,84 + 800,73 = 1 119,56 $<br>
    <b>Étape 2 :</b> 1 mois écoulé sur 6 = fraction 1/6 → 1 119,56 × (1,025)<sup>1/6</sup>
    <button class="reveler" data-cible="r-a14">👁 Révéler</button>
    <div id="r-a14" class="cache rep">P<sub>aujourd'hui</sub> = 1 119,56 × 1,00412 = <b>≈ 1 124,18 $</b></div>
  </div>
  <div class="exemple"><div class="titre-ex"><span class="num-exo">A15</span>(Exemple du cours) Dernier dividende trimestriel de 0,30 $ versé il y a 2 mois. r = 12 % nominal trim (3 %), g = 6 % nominal trim (1,5 %). Valeur intrinsèque?</div>
    <b>Étape 1 :</b> à la dernière date de versement : P = D₁/(r−g) = 0,30 × 1,015/(0,03 − 0,015) = 0,3045/0,015 = 20,30 $<br>
    <b>Étape 2 :</b> 2 mois écoulés = 2/3 de trimestre → 20,30 × (1,03)<sup>2/3</sup>
    <button class="reveler" data-cible="r-a15">👁 Révéler</button>
    <div id="r-a15" class="cache rep">P = 20,30 × 1,0199 = <b>≈ 20,70 $</b></div>
  </div>

  <h3>3.8 La démarche universelle en 4 étapes (à faire pour CHAQUE problème)</h3>
  <div class="retiens">
    <b>1. DESSINE le schéma temporel</b> (t=0, t=1, … les flux, en + ou −). — <i>« Toujours faire le schéma temporel pour ne pas faire d'erreur de période » (FAQ officielle)</i><br>
    <b>2. ALIGNE le taux</b> : convertis en taux périodique de la fréquence des versements (§3.5).<br>
    <b>3. REGROUPE</b> chaque série (montant simple / annuité / perpétuité [+ croissance]) — chaque formule « pose » son résultat à une date précise (une période avant le 1er versement).<br>
    <b>4. DÉPLACE</b> tous les résultats à la date demandée (capitaliser/actualiser en montant simple), puis additionne les + et les −.
  </div>

  <h2>🏦 Module 4 — Séance 3 : Les obligations</h2>

  <h3>4.1 C'est quoi, une obligation? (vocabulaire à connaître froid)</h3>
  <p>Une obligation, c'est un <b>titre de dette</b> : TU prêtes de l'argent (tu es le créancier), l'émetteur (gouvernement ou entreprise) s'engage à te rembourser le capital + les intérêts. Le contrat légal s'appelle l'<b>acte de fiducie</b>. Si aucun actif n'est donné en garantie, on parle plutôt de <b>débenture</b>. Les émissions gouvernementales sont garanties par la capacité de taxation de l'État.</p>
  <dl class="lexique">
    <dt>Valeur nominale (VN)</dt><dd>Le capital emprunté, remboursé à l'échéance — habituellement <b>1 000 $</b>.</dd>
    <dt>Coupon (TC)</dt><dd>L'intérêt versé périodiquement. Obligation « nord-américaine » standard = <b>2 coupons par année</b> → le TC est un <b>taux nominal à capitalisation semestrielle</b> (coupon semestriel = TC × VN / 2).</dd>
    <dt>Échéance</dt><dd>La date où la VN est remboursée.</dd>
    <dt>TRE / RAE (taux de rendement à l'échéance)</dt><dd>Le rendement EXIGÉ par le marché pour ce titre = le taux d'actualisation du prix. Lui aussi, en Amérique du Nord : <b>nominal semestriel</b> (taux périodique = TRE/2). <i>Sauf indication contraire de l'énoncé!</i></dd>
    <dt>Cote</dt><dd>Le prix exprimé en <b>% de la VN</b>. Cote de 102 % = prix de <b>1 020 $</b>. (Précision officielle de la prof!)</dd>
    <dt>Points de base</dt><dd>1 pb = 0,01 %. Une hausse de 50 pb = +0,50 %.</dd>
  </dl>

  <h3>4.2 Le prix d'une obligation conventionnelle (LE calcul à maîtriser)</h3>
  <p>Un obligation = <b>deux flux</b> à actualiser au taux périodique du TRE : ① les coupons = une <b>annuité</b>; ② la VN = un <b>montant simple</b> à l'échéance.</p>
  <div class="formule">P₀ = TC/2 × [1 − (1 + i)<sup>−n</sup>]/i + VN × (1 + i)<sup>−n</sup>
    <small>i = TRE/2 (taux semestriel) · n = nombre de SEMESTRES jusqu'à l'échéance · coupon semestriel = TC × VN/2</small>
  </div>
  <div class="exemple"><div class="titre-ex"><b>Exemple officiel du cours :</b> VN 1 000 $, TC 5 %, échéance exactement 12 ans, TRE exigé 8 %. Prix?</div>
    Coupon sem. = 5 % × 1 000/2 = <b>25 $</b> · i = 8/2 = <b>4 %</b> · n = 12 × 2 = <b>24</b><br>
    P = 25 × [1 − (1,04)<sup>−24</sup>]/0,04 + 1 000 × (1,04)<sup>−24</sup> = 25 × 15,2470 + 1 000 × 0,3901 = 381,17 + 390,12
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 24 <span class="touche">N</span> · 4 <span class="touche">I/Y</span> · 25 <span class="touche">PMT</span> · 1000 <span class="touche">FV</span> · <span class="touche">CPT</span> <span class="touche">PV</span> → −771.30</div>
    <div class="rep">P = <b>771,30 $</b> (réponse officielle) — l'obligation se vend à escompte (TRE &gt; TC).</div>
  </div>

  <h3>4.3 Par, prime, escompte (question théorique ultra-fréquente)</h3>
  <table>
    <tr><th> Situation</th><th>Prix</th><th>Analogie</th></tr>
    <tr><td><b>TRE = TC</b></td><td><b>Par</b> : prix = VN (1 000 $)</td><td>Le marché exige exactement ce que le coupon paie.</td></tr>
    <tr><td><b>TRE &lt; TC</b></td><td><b>Prime</b> : prix &gt; VN</td><td>Le coupon paie PLUS que ce que le marché exige → on paie un bonus.</td></tr>
    <tr><td><b>TRE &gt; TC</b></td><td><b>Escompte</b> : prix &lt; VN</td><td>Le coupon paie MOINS que requis → on achète à rabais.</td></tr>
  </table>

  <h3>4.4 Le zéro-coupon</h3>
  <p>Aucun coupon : tout le rendement vient de la différence entre le prix d'achat (bas) et la VN remboursée. Prix = <b>VC actualisée en montant simple</b> : P = VN/(1+i)ⁿ.</p>

  <h3>4.5 Obligations non conventionnelles (le niveau « expert » du quiz)</h3>
  <ul>
    <li><b>Capital remboursé en tranches</b> (ex. du TP2 : 250 $ aux 3 ans pendant 12 ans) → chaque tranche est un montant simple à sa date + les coupons restent une annuité pleine.</li>
    <li><b>Coupons différés</b> (ex. officiel : le 1er coupon dans 3 ans) → l'annuité est « posée » une période avant le premier coupon, PUIS actualisée jusque-là. Voir l'exercice B2 ci-dessous.</li>
  </ul>

  <h3>4.6 Le RAE quand on connaît le prix (calculatrice obligatoire)</h3>
  <p>On ne peut pas isoler i algébriquement : la calculatrice le trouve par itération (c'est le « tâtonnement » du livre, mais automatique et instantané). Voir le <a href="#calculatrice">Geste E</a> du module 1.</p>

  <h3>4.7 Clauses optionnelles et leur effet sur le prix</h3>
  <table>
    <tr><th>Clause</th><th>Qui a l'option?</th><th>Effet sur le prix (toutes choses égales par ailleurs)</th></tr>
    <tr><td><b>Rétractable</b> (puttable)</td><td>Le détenteur peut « retourner » le titre (prix/période fixés)</td><td><b>+</b> (avantage à l'acheteur)</td></tr>
    <tr><td><b>Rachetable</b> (callable)</td><td>L'émetteur peut racheter le titre (prix/période fixés)</td><td><b>−</b> (risque pour l'acheteur)</td></tr>
    <tr><td><b>Convertible</td><td>Le détenteur peut convertir en actions</td><td><b>+</b></td></tr>
    <tr><td>Liquidité élevée</td><td>—</td><td><b>+</b></td></tr>
    <tr><td>Meilleure cote de crédit</td><td>—</td><td><b>+</b></td></tr>
  </table>

  <h3>4.8 Risque de crédit et cotes</h3>
  <p>Le <b>risque de crédit</b> = probabilité que l'émetteur fasse défaut. Les agences (<b>S&amp;P, Moody's, Fitch</b>) publient des cotes, révisées selon la firme et l'économie. Deux catégories : <b>qualité investissement</b> (investment grade) vs <b>pacotille</b> (non-investment grade / high-yield / junk bonds).</p>

  <h3>4.9 Effet Fisher (l'inflation) ⭐</h3>
  <div class="formule">(1 + r<sub>nominal</sub>) = (1 + r<sub>réel</sub>) × (1 + inflation)<br><small>Approximation rapide : r<sub>nominal</sub> ≈ r<sub>réel</sub> + inflation</small></div>
  <div class="exemple"><div class="titre-ex">Exemple du cours : tu places 10 $ à 8 % pour un an; le sac de lait à 10 $ coûtera 10,30 $ dans un an (inflation 3 %).</div>
    Ton 10,80 $ de l'an prochain achète l'équivalent de 10,80/1,03 = 10,49 $ d'aujourd'hui → rendement RÉEL = (1,08/1,03) − 1 = <b>4,85 %</b> (et non 8 − 3 = 5 %, l'approximation).
  </div>

  <h3>4.10 La structure à terme des taux (la courbe)</h3>
  <p>La courbe des taux = niveau des TRE selon l'échéance. Elle reflète <b>inflation + taux réel + prime de risque</b>, et « représente en quelque sorte l'anticipation des taux futurs » :</p>
  <table>
    <tr><th>Forme</th><th>Anticipation du marché</th></tr>
    <tr><td><b>Normale</b> (croissante)</td><td>Hausse anticipée des taux</td></tr>
    <tr><td><b>Pentification</b> (elle se redresse)</td><td>La hausse sera PLUS marquée qu'initialement anticipé</td></tr>
    <tr><td><b>Aplatissement</b></td><td>La hausse sera MOINS marquée qu'anticipé (ou aucune hausse)</td></tr>
    <tr><td><b>Inversée</b> (décroissante)</td><td>BAISSE anticipée des taux</td></tr>
  </table>

  <h3>4.11 La durée (concepts SEULEMENT — « aucun calcul de durée n'est requis »)</h3>
  <div class="encadre">La durée mesure la <b>volatilité du prix</b> par rapport aux taux d'intérêt (les FMs « moyens pondérés par le temps » — le point d'équilibre de la balançoire des flux). Règles :
  <ul>
    <li>À <b>même taux de coupon</b> : échéance élevée → durée <b>élevée</b>;</li>
    <li>À <b>même échéance</b> : coupon élevé → durée <b>faible</b> (les gros coupons reviennent vite).</li>
  </ul>
  <b>Application stratégique officielle :</b> si tu anticipes une <b>baisse des taux</b>, achète la duration la plus LONGUE (ex. : coupon 3 %, échéance lointaine) pour maximiser le gain de prix. Si tu anticipes une <b>hausse</b>, la plus COURTE (coupon élevé, échéance proche).</div>

  <h2>📈 Module 5 — Séance 4 : L'évaluation des actions</h2>
  <p>Même principe universel : <b>le prix d'un titre = la valeur actualisée de TOUS ses flux monétaires futurs</b>. Pour une action, les flux = les <b>dividendes</b>. On n'a besoin que des 3 formules déjà apprises (montant simple, annuité, perpétuité).</p>

  <h3>5.1 Action ordinaire vs privilégiée (théorie)</h3>
  <table>
    <tr><th></th><th>Action ORDINAIRE</th><th>Action PRIVILÉGIÉE</th></tr>
    <tr><td>Droit de vote</td><td><b>Oui</b> (élire le conseil d'administration)</td><td><b>Non</b> (sauf contingences : report prolongé du dividende, nouvelles émissions…)</td></tr>
    <tr><td>Dividendes</td><td>Variables, croissants (bénéfices résiduels versés ou réinvestis — BNR)</td><td><b>Constants</b>, habituellement <b>cumulatifs</b> (les dividendes non versés sont reportés)</td></tr>
    <tr><td>Rang en faillite</td><td><b>Dernier</b></td><td>Senior aux ordinaires, subordonné à la dette</td></tr>
    <tr><td>Évaluation</td><td>Perpétuité/growth (Gordon)</td><td><b>Perpétuité simple</b></td></tr>
  </table>

  <h3>5.2 Actions privilégiées = perpétuité</h3>
  <div class="formule">P₀ = D / r
    <small>D = dividende constant (par période) · r = rendement exigé PAR PÉRIODE (même fréquence que D) · valeur une période avant le prochain dividende</small>
  </div>
  <div class="exemple"><div class="titre-ex"><b>Exemple officiel 1 :</b> privilégiée BDB, dividende annuel 1 $, rendement exigé 8 %.</div>
    P = 1/0,08 = <b>12,50 $</b> (réponse officielle)</div>
  <div class="exemple"><div class="titre-ex"><b>Exemple officiel 2 :</b> privilégiée BDB, dividende TRIMESTRIEL de 0,25 $, rendement exigé EFFECTIF 8 %.</div>
    ⚠️ Piège : les dividendes sont trimestriels → il faut le taux TRIMESTRIEL : i<sub>trim</sub> = (1,08)<sup>1/4</sup> − 1 = 1,94265 %<br>
    P = 0,25/0,0194265 = <b>12,87 $</b> (réponse officielle)
  </div>

  <h3>5.3 Actions ordinaires — le modèle de Gordon-Shapiro (croissance constante)</h3>
  <div class="formule">P₀ = D₁ / (r − g) = D₀ × (1 + g) / (r − g)
    <small>D₁ = PROCHAIN dividende (une période plus tard!) · r = rendement exigé par période · g = croissance par période · r &gt; g</small>
  </div>
  <div class="danger"><b>🚨 LE piège du quiz : D₁ vs D₀.</b> « Vient tout juste de verser un dividende de 1 $ » = c'est D₀ → D₁ = 1 × (1+g). « Le prochain dividende sera de X » = c'est déjà D₁, ne multiplie PAS. (FAQ officielle : « vient tout juste d'être versé » ou « prochain dividende dans exactement une période » → premier flux à t=1.)</div>
  <div class="exemple"><div class="titre-ex"><b>Exemple officiel :</b> IBN vient de verser 1 $ (D₀). Croissance prévue 5 %, rendement exigé 14 %. Prix?</div>
    D₁ = 1 × 1,05 = 1,05 $ → P₀ = 1,05/(0,14 − 0,05) = 1,05/0,09 = <b>11,67 $</b><br>
    <span class="cle">Sources du rendement si tes anticipations sont correctes (question officielle du PPT) : le <b>dividende</b> (rendement du dividende) + le <b>gain en capital</b> (le prix croît au même rythme g que les dividendes).</span>
  </div>

  <h3>5.4 Croissance non constante (le « modèle en 2 étapes ») — décomposition</h3>
  <div class="retiens"><b>Méthode officielle (décomposition de la structure des FMs) :</b>
  <ol>
    <li>Dessine les dividendes avec leurs croissances spécifiques (ex. 20 %, 15 %, puis 5 % à l'infini);</li>
    <li>Actualise les dividendes « anormaux » un à un en <b>montants simples</b>;</li>
    <li>À la date où la croissance devient constante, pose le <b>Gordon</b> (P<sub>t</sub> = D<sub>t+1</sub>/(r−g)) — cette valeur « vit » à cette date-là;</li>
    <li>Actualise ce prix de fin en montant simple et <b>additionne tout</b>.</li>
  </ol>
  <span class="cle">Le cours préfère cette décomposition à la formule d'annuité en croissance — mais les deux donnent le même résultat.</span></div>
  <div class="exemple"><div class="titre-ex"><b>Exemple officiel (suite IBN) :</b> croissance 20 % (an 1), 15 % (an 2), puis 5 % à l'infini. r = 14 %, D₀ = 1 $.</div>
    D₁ = 1,20 · D₂ = 1,38 · D₃ = 1,449 (croissance normale 5 %)<br>
    Gordon à t=2 : P₂ = D₃/(r−g) = 1,449/0,09 = 16,10 $<br>
    P₀ = 1,20/1,14 + (1,38 + 16,10)/1,14² = 1,0526 + 17,48/1,2996
    <button class="reveler" data-cible="r-d1">👁 Révéler</button>
    <div id="r-d1" class="cache rep">P₀ = 1,0526 + 13,45 = <b>≈ 14,50 $</b> (on peut aussi décomposer avec P₃ = D₄/(r−g) actualisé d'une période de plus — même résultat)</div>
  </div>

  <h3>5.5 L'évaluation par multiple C/B (P/E)</h3>
  <p>Méthode <b>simplifiée</b>, moins d'hypothèses que les dividendes : on compare la société à son industrie.</p>
  <div class="formule">C/B = Cours / Bénéfices des 4 derniers trimestres &nbsp;&nbsp;→&nbsp;&nbsp; Valeur intrinsèque = C/B<sub>industrie</sub> × BPA
    <small>Autres multiples : P/B, EV/EBIT, EV/EBITDA, P/clic…</small>
  </div>
  <div class="exemple"><div class="titre-ex"><b>Exemple officiel :</b> cours 90 $, bénéfices 4 trimestres = 2 + 1,50 + 2,50 + 1,50 = 7,50 $. Multiple de l'industrie : 14.</div>
    C/B = 90/7,50 = 12 fois (&lt; 14 → l'action semble sous-évaluée)<br>
    Valeur intrinsèque = 14 × 7,50 = <b>105 $</b> (réponse officielle)
  </div>

  <h2>✍️ Module 6 — Les 5 questions solutionnées officielles du cours</h2>
  <p>Ce sont les questions que la prof a publiées dans les pages « APRÈS la séance » avec leur capsule vidéo de solution. <b>Protocole (16h50-18h20) :</b> cache la solution, essaie 10 minutes sur papier avec schéma temporel, puis compare. Ces questions sont du niveau quiz.</p>

  <h3>Q1 — Le problème de retraite (math fin, chap. 5-6)</h3>
  <div class="exemple"><div class="titre-ex">Énoncé officiel</div>
    Une amie fête ses 35 ans aujourd'hui. Elle veut retirer <b>80 000 $ par année</b> de son compte, le jour de ses <b>66 ans, et ce pendant 15 ans</b> (dernier retrait à 80 ans). Taux : <b>9 % par année</b>.<br>
    a) Versements égaux <b>de 36 à 65 ans inclusivement</b> (dernier le jour des 65 ans) : quel montant annuel?<br>
    b) Montant <b>forfaitaire le jour de ses 36 ans</b> pour combler le même objectif?<br>
    c) Idem que a), mais l'employeur verse <b>1 500 $/an</b> dans le compte et elle recevra <b>30 000 $ à 55 ans</b> : quel versement annuel personnel?
  </div>
  <button class="reveler" data-cible="r-q1">👁 Révéler la solution complète</button>
  <div id="r-q1" class="cache">
    <p><b>Étape 1 — la cible (à 65 ans) :</b> les retraits forment une annuité de 15 × 80 000 $, dont le premier est à 66 ans → VAA « posée » une période avant = à 65 ans :<br>
    VA<sub>65</sub> = 80 000 × [1 − (1,09)<sup>−15</sup>]/0,09 = 80 000 × 8,0607 = <b>644 855 $</b></p>
    <p><b>a)</b> À 35 ans, elle commence des versements de fin de période de 36 à 65 ans = 30 versements, dont la VAA tombe à 35 ans. Il faut la <b>capitaliser 30 ans</b> jusqu'à 65 ans (ou : VFA à 65 ans) :<br>
    644 855 = PMT × [(1,09)<sup>30</sup> − 1]/0,09 = PMT × 136,31 → PMT = <b>≈ 4 731 $/an</b></p>
    <p><b>b)</b> Forfaitaire à 36 ans → capitalise 29 ans jusqu'à 65 ans :<br>
    Montant = 644 855/(1,09)<sup>29</sup> = 644 855/12,1713 = <b>≈ 52 980 $</b></p>
    <p><b>c)</b> Les aides de l'employeur capitalisent elles aussi vers 65 ans :<br>
    1 500 $/an pendant 30 ans : VFA = 1 500 × 136,31 = 204 461 $<br>
    30 000 $ à 55 ans → × (1,09)<sup>10</sup> = 71 021 $<br>
    Reste à combler : 644 855 − 204 461 − 71 021 = <b>369 373 $</b> → PMT = 369 373/136,31 = <b>≈ 2 710 $/an</b></p>
    <p class="cle">Concepts : la ligne du temps règne; une annuité « tombe » à une date précise; on déplace tout à la même date avant de comparer.</p>
  </div>

  <h3>Q2 — Chréphane : trouver le COUPON à partir de la cote (obligations)</h3>
  <div class="exemple"><div class="titre-ex">Énoncé officiel</div>
    Il y a <b>5 ans et demi</b>, Chréphane a émis des obligations à <b>20 ans</b> d'échéance initiale. Le TRE actuel est de <b>9 %</b> et les titres se vendent à une <b>cote de 85 %</b>. Quel était le taux de coupon offert à l'émission? <i>(La prof demande de le trouver à la calculatrice plutôt qu'Excel.)</i>
  </div>
  <button class="reveler" data-cible="r-q2">👁 Révéler la solution complète</button>
  <div id="r-q2" class="cache">
    <p><b>Décorticage :</b> émise il y a 5,5 ans sur 20 → reste <b>14,5 ans = 29 semestres</b>. TRE 9 % nominal sem. → i = 4,5 %. Cote 85 % × VN 1 000 $ = <b>prix 850 $</b>. Inconnue : le coupon semestriel PMT.</p>
    <p><b>Équation écrite :</b> 850 = PMT × [1 − (1,045)<sup>−29</sup>]/0,045 + 1 000 × (1,045)<sup>−29</sup> = PMT × 16,0212 + 279,05<br>
    → PMT = (850 − 279,05)/16,0212 = <b>35,64 $/semestre</b> → TC = 35,64 × 2/1 000 = <b>≈ 7,13 % nominal semestriel</b></p>
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 29 <span class="touche">N</span> · 4.5 <span class="touche">I/Y</span> · 850 <span class="touche">+/−</span> <span class="touche">PV</span> · 1000 <span class="touche">FV</span> · <span class="touche">CPT</span> <span class="touche">PMT</span> → 35.64 (×2 = 71,28 → TC ≈ 7,13 %)</div>
    <p class="cle">Cohérence : cote 85 % (escompte) → TC &lt; TRE (7,13 % &lt; 9 %) ✓</p>
  </div>

  <h3>Q3 — BDJ : le coupon d'une NOUVELLE obligation vendue au pair (obligations)</h3>
  <div class="exemple"><div class="titre-ex">Énoncé officiel</div>
    BDJ veut émettre une nouvelle obligation de <b>10 ans</b>. Elle possède déjà des obligations au coupon de <b>8 %</b> (semestriel, 10 ans) qui se vendent <b>1 095 $</b>. Quel devrait être le taux de coupon de la nouvelle obligation pour qu'elle se vende <b>à la valeur nominale</b>?
  </div>
  <button class="reveler" data-cible="r-q3">👁 Révéler la solution complète</button>
  <div id="r-q3" class="cache">
    <p><b>Étape 1 — le TRE du marché</b> (c'est lui qui fixera le coupon d'une émission au pair) : obligation existante : 1 095 = 40 × [1−(1+i)<sup>−20</sup>]/i + 1000(1+i)<sup>−20</sup> → par calculatrice :</p>
    <div class="seq"><span class="touche">2ND CLR TVM</span> · 20 <span class="touche">N</span> · 1095 <span class="touche">+/−</span> <span class="touche">PV</span> · 40 <span class="touche">PMT</span> · 1000 <span class="touche">FV</span> · <span class="touche">CPT</span> <span class="touche">I/Y</span> → ≈ 3,34 % semestriel</div>
    <p><b>Étape 2 —</b> Pour vendre au pair, TC = TRE → <b>TC = 2 × 3,34 % ≈ 6,68 % nominal semestriel</b>.</p>
    <p class="cle">Logique clé : au pair ⇔ TC = TRE. Le prix de 1 095 $ (prime) nous révèle le TRE du marché pour cette échéance/risque.</p>
  </div>

  <h3>Q4 — Entendus inc. : Gordon simple + prix futur (actions)</h3>
  <div class="exemple"><div class="titre-ex">Énoncé officiel</div>
    Entendus vient de verser un dividende annuel de <b>1,75 $</b>. Croissance constante <b>6 %</b> à l'infini, rendement exigé <b>12 %</b>. Cours actuel? Cours dans 3 ans? Dans 15 ans? <i>(Erratum officiel : à t=15, on utilise D₁₆ — pas D₁₄.)</i>
  </div>
  <button class="reveler" data-cible="r-q4">👁 Révéler la solution complète</button>
  <div id="r-q4" class="cache">
    <p>P₀ = D₁/(r−g) = 1,75 × 1,06/0,06 = 1,855/0,06 = <b>30,92 $</b></p>
    <p>P₃ = D₄/(r−g) = 1,75 × (1,06)⁴/0,06 = 2,2093/0,06 = <b>36,82 $</b></p>
    <p>P₁₅ = D₁₆/(r−g) = 1,75 × (1,06)¹⁶/0,06 = 4,4456/0,06 = <b>74,09 $</b></p>
    <p class="cle">Concept : à chaque date t, le prix = valeur des dividendes FUTURS à partir de t+1 → le prix croît au rythme g. (P₃ = P₀ × 1,06³ ✓)</p>
  </div>

  <h3>Q5 — Villa : croissance en 2 étapes (actions)</h3>
  <div class="exemple"><div class="titre-ex">Énoncé officiel</div>
    Villa versera : 6,50 $ (an 1), 5,00 $ (an 2), 3,00 $ (an 3), 2,00 $ (an 4), puis croissance constante de <b>5 % à l'infini</b>. Rendement exigé <b>16 %</b>. Cours actuel?
  </div>
  <button class="reveler" data-cible="r-q5">👁 Révéler la solution complète</button>
  <div id="r-q5" class="cache">
    <p><b>Décomposition :</b> dividendes explicites D₁–D₃ en montants simples; Gordon posé à t=3 (une période avant D₄) : P₃ = D₄/(r−g) = 2,00/0,11 = <b>18,18 $</b></p>
    <p>P₀ = 6,50/1,16 + 5,00/(1,16)² + (3,00 + 18,18)/(1,16)³<br>
    = 5,6034 + 3,7159 + 21,18/1,5609 = 5,6034 + 3,7159 + 13,5715 = <b>≈ 22,89 $</b></p>
    <p class="cle">Concept : peu importe la forme des premiers dividendes (même décroissants!), la méthode ne change jamais : montants simples + Gordon à la stabilisation.</p>
  </div>

function brancherQcm(){
  document.querySelectorAll('.qcm:not([data-pret])').forEach(q=>{

    const bonne=q.dataset.rep;
    const fb=q.querySelector('.feedback');

        const explication=q.dataset.exp || '';
        if(num===bonne){
          opt.classList.add('bonne');
          fb.className='feedback ok';
          fb.innerHTML='✅ <b>Bravo!</b> '+(q.dataset.ok||'')+(explication?'<br><span class="cle">'+explication+'</span>':'');

          q.querySelector('button.opt[data-i="'+bonne+'"]').classList.add('bonne');

          fb.innerHTML='❌ Pas tout à fait. La bonne réponse est surlignée en vert. '+(q.dataset.ko||'')+(explication?'<br><span class="cle">'+explication+'</span>':'');

        q.dataset.verrouille='1';
      });
    });
  });
}
brancherQcm();

/* ===== Horaire : bloc en cours ===== */
function minDepuisMinuit(h){ const [H,M]=h.split(':').map(Number); return H*60+M; }
function majHoraire(){
  const maintenant=new Date();
  const cur=maintenant.getHours()*60+maintenant.getMinutes();
  const jour=maintenant.getDay(); // 0=dimanche
  document.querySelectorAll('#tab-horaire tr[data-debut]').forEach(tr=>{
    const d=minDepuisMinuit(tr.dataset.debut), f=minDepuisMinuit(tr.dataset.fin);
    tr.classList.remove('maintenant','passe');
    if(jour===0){ if(cur>=d&&cur<f) tr.classList.add('maintenant'); else if(cur>=f) tr.classList.add('passe'); }
  });
}
majHoraire(); setInterval(majHoraire, 30000);
